# Conversor-de-bases
Conversor de bases numéricas desenvolvido com HTML, CSS e JavaScript.

Sobre o projeto
Este é um conversor de bases numéricas desenvolvido em HTML, CSS e JavaScript. O objetivo do projeto é permitir a conversão de números entre diferentes bases de forma simples e rápida, além de colocar em prática os conhecimentos adquiridos durante os estudos de programação.
Foi um projeto desafiador, principalmente na implementação da lógica de conversão, mas que contribuiu bastante para o aprendizado.

---

Funcionalidades
- Converter números entre diferentes bases;
- Suporte às seguintes bases:
  - Binária (Base 2);
  - Quinária (Base 5);
  - Octal (Base 8);
  - Decimal (Base 10);
  - Hexadecimal (Base 16);
- Interface simples e fácil de utilizar;
- Validação das entradas para evitar valores inválidos.

---

Tecnologias utilizadas
- HTML
- CSS
- JavaScript

---

Como utilizar
1. Digite o número que deseja converter;
2. Selecione a base de origem;
3. Escolha a base de destino;
4. Clique no botão de conversão;
5. O resultado será exibido na tela.

---

Objetivo
Este projeto foi desenvolvido como atividade de estudo para praticar lógica de programação, manipulação de funções e desenvolvimento web. Além de atender aos requisitos da atividade, ele serviu para aprofundar meus conhecimentos sobre conversão entre sistemas de numeração.
